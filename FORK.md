# Fork Notice

This repository is based on `AxiomMath/axiom-lean-engine` and is being developed as an AXLE-rs fork workspace.

The original AXLE project provides Lean proof verification and proof manipulation utilities. This workspace explores a Rust-native artifact layer for AXLE-compatible proof outputs, including `.axle` portable artifacts, content-addressed proof objects, artifact inspection, artifact verification, and optional receipt binding.

This project is experimental and is not an official Axiom Math release unless otherwise stated.
