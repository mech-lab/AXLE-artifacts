# Fork Notice

This repository is based on `AxiomMath/axiom-lean-engine` and is being developed as the AXLE-rs fork workspace.

The upstream AXLE project provides Lean proof verification and proof-manipulation utilities. AXLE-rs explores a complementary Rust-native artifact layer for AXLE-compatible outputs, including `.axle` portable artifacts, canonical hashing, artifact inspection, provenance metadata, and later receipt or object-graph work.

The `docs/` tree in this repository is still preserved upstream AXLE-facing documentation for the Python client, hosted API, and existing CLI/tool surface. AXLE-rs-specific narrative and planning live primarily in the root documentation and `spec/`.

This project is experimental and is not an official Axiom Math release unless otherwise stated.
